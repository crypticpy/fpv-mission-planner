# R-VALIDATION — human-subject-free validation corpus for mountain-flow and route-wide terrain

Assembled per `research/AI_AGENT_DEVELOPMENT_PLAN.md`'s research table (R-VALIDATION row:
"Assemble open DEM, terrain, and wind reference cases usable without human subjects" →
"Licensed fixture corpus with provenance" → decision influenced: "Automated terrain/wind
validation"). This targets Milestone 5 (Mountain-flow advisory system: Baseline 1
`w* = V · ∇h`, Baseline 2 `Fr = U / (N h)` regime classification) and the route-wide
terrain milestone. No datasets were downloaded or committed; every row below is a
pointer plus enough qualitative/quantitative detail to write an assertion against.

## Notes on items not fully resolved

- **Bolund** download mechanics could not be confirmed without contacting DTU directly — treat the raw sensor data as "registration/contact required," but the two peer-reviewed papers' published numbers (FSR, TKE, blind-test error bars) are freely citable today and sufficient for a tolerance-band fixture.
- **Perdigão** is fully open today (its 12-month embargo expired in 2018) but is multi-GB; nothing here recommends bulk download.
- The WindNinja `autotest/` C++ suite is not a bundled-fixture set — it hits live DEM providers (SRTM/COP30/GMTED) over the network at test time, unlike the small static tiles in `data/`.

## Recommendation — build these first (priority order)

1. **Analytic Witch-of-Agnesi / Jackson-Hunt synthetic ridge** (row 4). Zero download, zero license risk, immediate unit coverage for Baseline 1's `w*` sign/magnitude pattern and for 3D-scene ridge/lee rendering tests. Do this first.
2. **Froude-regime lookup table** (row 5). Also zero download — a hardcoded `(U, N, h) → regime` test table citing AMS Glossary + Reinecke & Durran (2008) + Whiteman (2000), directly exercising Baseline 2's classifier.
3. **WindNinja `mackay_small.tif` (167 KB) + `denali.tif` (194 KB)** (row 11). The smallest already-licensed, already-committed real DEM tiles available anywhere in this survey — use them (by reference, or re-clipped at the same small size) to run the "optional WindNinja comparison" the milestone's exit gate already asks for.
4. **Askervein Zenodo files** (row 1, CC BY 4.0, ~1.9 MB, zero registration friction). The one classic field campaign with no access barrier at all — use its documented windward-accel/lee-decel sign pattern over a real (non-idealized) hill as a second, independent qualitative check on Baseline 1.
5. **One small SRTM clip** via OpenTopography bbox API over an existing app preset location (row 10, preferred over Copernicus for this slot purely because it carries no attribution obligation at all). This is the one genuinely new small download the team would actually need to perform, and it is the fixture that most directly exercises the route-wide terrain milestone against a real DEM rather than a synthetic one.

Bolund and Perdigão are deliberately not in the first-five list: Bolund's access path is unconfirmed and Perdigão is disproportionately large for what Milestone 5's automated gates need. Both remain good stretch fixtures once 1–5 are running.

## Decision impact

- Closes the "comparisons against open WindNinja or published reference cases are recorded" bullet in Milestone 5's automated exit gate (`research/AI_AGENT_DEVELOPMENT_PLAN.md`) — items 3 and 4 above are exactly such comparisons, sourced and licensed.
- Confirms Baseline 1 and Baseline 2 can each get a **human-subject-free, automatable** correctness fixture (sign pattern and regime classification) before any pilot-interpretation testing — the pilot-blinded-map-interpretation study named in `research/3d-terrain-mountain-wind-feasibility-artifact.json`'s validation section remains a separate, later, human-subject step this corpus does not and cannot substitute for.
- Confirms committing a small clipped Copernicus or SRTM DEM extract is license-clean (Copernicus requires the Article 6(b) attribution notice quoted above; SRTM requires none), removing a licensing blocker for the route-wide terrain milestone's synthetic/real DEM fixtures.
- FAA-H-8083-28 §16.2.1–16.2.7 and §19.2.2/19.2.5 give section-numbered backing for every hazard term already in the warning taxonomy (gravity wave, K-H wave, vertically propagating mountain wave, trapped lee wave, rotor, mechanical/orographic turbulence) — no taxonomy term currently in use lacks a citable FAA section.
